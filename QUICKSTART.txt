🚀 CRYPTO BOT - QUICKSTART (5 MIN)
════════════════════════════════════════════════════════════════════════

⚡ SOLO NECESITAS 3 PASOS:

┌─────────────────────────────────────────────────────────────────┐
│ PASO 1: CREAR DISCORD WEBHOOK (2 MIN)                          │
└─────────────────────────────────────────────────────────────────┘

1. Ve a: https://discord.new
2. Click "Create My Own" → "For me and my friends"
3. Nombre: "Crypto Bot" → "Create"
4. Click en "+" (crear canal) → "alerts" → "Create"
5. En #alerts: Click ⚙️ → Integrations → Webhooks → New Webhook
6. Nombre: "CryptoBot"
7. Click "Copy Webhook URL"

🔗 GUARDA ESTA URL - LA NECESITARÁS

════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│ PASO 2: SETUP LOCAL (2 MIN)                                    │
└─────────────────────────────────────────────────────────────────┘

Windows (PowerShell):
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt

Mac/Linux (Terminal):
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt

════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│ PASO 3: CONFIGURAR WEBHOOK                                      │
└─────────────────────────────────────────────────────────────────┘

1. Crea archivo: .env
2. Dentro, escribe:

   DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/TU_URL_AQUI

3. Reemplaza TU_URL_AQUI con tu webhook URL real
4. Guarda
